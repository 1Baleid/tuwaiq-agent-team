- **Decisions and why:**

  - **Document search is a tool:** the small model ignored other tools whenever search text was already in the prompt.
  - **Citations look like `[course_credit.txt#3]`.**
  - **FAISS, not ChromaDB:** one clean install versus about 84 packages.
  - **Laptop versions equal Colab's;** in Colab only `faiss-cpu` and `pypdf` are installed.
