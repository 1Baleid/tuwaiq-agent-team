- **Decisions and why:**
  - **Groq (`gpt-oss-20b`) is the best candidate:** about 2 s per question.
  - **Gemini Flash-Lite is the backup:** about 20 s per question.
  - **OpenRouter is ruled out:** 50 requests per day, and failed requests count.
  - **The fallback is a small local model** (Ollama + `qwen3:4b-instruct`, 10/10 on tool calls), and it needs a Colab **GPU**.
  - **Tool calls will be plain JSON with examples,** because that works on every provider.

  - Free Colab doesn't promise a GPU.
  - Gemini no longer publishes its limits.
  - Model names change monthly (Groq removed Llama in August).
