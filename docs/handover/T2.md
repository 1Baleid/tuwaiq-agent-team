# Handover T2: LLM access decision (2026-11-02)

- **Status:** Partly done.
  - The load-test script works, and the fallback is proven: switching `LLM_PROVIDER` to `"local"` passed the test.
  - **Missing:** the Groq and Gemini runs, which need API keys. That's 4 commands, about 15 minutes.
- **What was built** (branch `main`):
  - `scripts/load_test.py`: (a) N students calling at once with one key, (b) one student's burst of questions.
  - `docs/llm_decision.md`: the recommendation and the results table.
- **How to check:** put keys in `.env`, then run `python scripts/load_test.py burst`. It prints PASS or FAIL, the success rate, the 429 count and p50/p95 times.
- **Decisions and why:**
  - **Every student gets their own free Groq key, plus a Gemini key as a backup.** One shared free key gives the whole class one person's limit (about 7 calls per minute), and the providers' rules forbid sharing keys.
  - **The fallback is a local model in each student's own Colab.** One shared local server queued for up to 2 minutes in our test.
- **Open issues and risks:**
  - The final provider choice needs Abdullah's OK.
  - Groq's 8K tokens/minute may still throttle fast students. The Groq burst test will show this.
  - Under-18 students can't use any of the free APIs.
