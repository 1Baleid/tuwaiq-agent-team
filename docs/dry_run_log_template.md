# Dry-run issue log (template)

**What a dry run is:** before students see a session, two teammates who did **not** write it run it exactly
as a student would, on a fresh Colab. Every problem they hit goes in this log. Then each item is fixed, or
consciously accepted. (Delivery plan: Sessions 1–2 on Day 5, Sessions 3–5 on Day 6.)

**How to fill it in:** one row per problem. Copy error messages **exactly** (or attach a screenshot).
Then give the whole file to whoever fixes the repo (ticket T7). It comes back with each row marked
fixed / accepted / open.
